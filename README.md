# 启航AI工作台 —— 个人 AI 助手

> 一款以**数据流为核心**的个人 AI 助手，与 WorkBuddy、千问办公、Trae Work 同类，但更强调"本地优先、模型自由、数据流转起来"——你的笔记、待办、工作数据都留在本机，AI 融入数据的采集、检索、执行与复盘全流程，而不只是一个聊天窗口。

启航AI工作台是一款桌面应用，把 **本地笔记知识库**、**结构化数据**、**待办提醒**、**飞书推送** 和 **AI 智能体** 整合成一套完整的数据流。所有数据都保存在你的电脑上，AI 模型可以自由选择（支持 DeepSeek、OpenAI 兼容接口，也可以使用本地 Ollama 完全离线运行）。

---

## ✨ 核心卖点：一条完整的自动化链路

别的 AI 助手是"对话框 + 一堆孤立功能"，启航AI工作台是一套完整的流程：

```
采集 → 分析 → 建议 → 执行 → 推送
```

```
📝 采集 ──索引──▶ 📚 知识库 ──分析──▶ 💬 AI 分析建议
（笔记/数据）      （向量+全文）        （回答问题/查数据集）
                                        │
  🔗 推送 ◀── 📋 日报复盘 ◀──汇总── ✅ 执行 ◀──┘
 （飞书对接）      （每日自动生成）      （待办/记录落地）
```

**五个环节，环环相扣：**

1. **采集**：Markdown 笔记随手记，Excel/JSON 数据批量导入，自动索引进本地知识库（向量 + 全文检索）。
2. **分析**：AI 基于你的笔记和数据回答提问、查数据集、读文件，而不是凭空瞎编。
3. **建议**：AI 不只是回答问题，还给出可执行的建议——该做的事、该记的档、该跟进的事项。
4. **执行**：对话中产生的任务、记录直接落成待办和数据集，AI 还能读写笔记文件、操作本地数据。
5. **推送**：定时提醒、每日 AI 日报自动汇总笔记/任务/对话，通过**飞书对接**推送到你的群和联系人。

> 全程数据留在本机，模型可自由选择，形成"采集 → 分析 → 建议 → 执行 → 推送"的完整闭环。

## 其他优势

- 🔒 **基于本地知识库 · 数据安全**：笔记、索引、对话记录、待办全部存在本机，不上传任何云端，无第三方数据泄露风险。
- 🧠 **不绑定大厂模型 · 可扩展**：模型自由插拔，随时切换或接入新服务商；使用 Ollama 本地模型可完全离线。
- 🚀 **随 Agent 引擎持续升级**：底层对话与工具调用引擎（pi agent）由官方持续迭代，能力自动进化，无需重构。

| 📚 **知识库** | 导入你的 Markdown 笔记目录，自动索引，AI 基于你的笔记回答问题（RAG 语义检索） |

## 快速开始

```bash
# 1. 安装依赖（需要 Node.js 18+）
npm install

# 2. 启动应用
npm run electron:dev
```

> 应用启动后，建议先进入「设置」完成模型配置（见下文），再开始使用。

## 配置指南

### 1. LLM 对话模型（必配）
「设置 → 模型」中可配置多个模型档案并设置默认：

- **DeepSeek**：填 `API Key`，选择模型（如 `deepseek-chat`）
- **OpenAI 兼容接口**：任何 OpenAI 兼容的服务商，填 `Base URL` + `API Key` + 模型名
- **Ollama（本地/离线）**：填 Ollama 服务地址（默认 `http://127.0.0.1:11434`）和已下载的模型名
- 配置后可「测试连接」验证；工作台对话时也可临时切换模型

### 2. 嵌入模型（知识库语义检索）
「设置 → 嵌入模型」用于笔记向量化：

- 推荐 **Ollama bge-m3**（本地免费）
- 也可使用 OpenAI 兼容的 embedding 接口（填 `API Key`）
- 配置后需对知识库执行「重新索引」

### 3. 飞书集成
- **Webhook 推送**：粘贴飞书群机器人 Webhook 地址，AI 日报、提醒即可推送到群
- **Bot 对话**：在飞书开放平台创建应用，填 `App ID` / `App Secret`，启动后可在飞书私聊/群聊中直接使用 AI

### 4. 定时任务与日报
「设置 → 定时任务」中可配置：

- **自动日报**：每天定时汇总笔记、任务、对话生成日报（可自定义提示词模板，推送到飞书）
- **自动索引**：定时增量索引知识库

## 数据与隐私

- 所有数据保存在应用目录下的本地数据库（`memory.db`）与你的笔记文件夹中。
- 对话内容默认会发送给你配置的模型服务商（DeepSeek 等）用于生成回复。
- 如需**完全离线**：使用 Ollama 作为对话模型与嵌入模型即可（除软件自动更新外无任何网络请求）。
- 建议定期备份 `memory.db` 和笔记目录；后续版本将提供一键备份/恢复。

## 常见问题（FAQ）

**Q：AI 答非所问，没有用到我的笔记？**
A：确认知识库已添加并完成索引（概览页或知识库页可触发重新索引），并在工作台选择了对应的知识库项目。

**Q：提示"模型连接失败"？**
A：检查设置页的模型配置，点「测试连接」；Ollama 需先 `ollama pull <模型名>` 并确保服务已启动。

**Q：可以完全离线使用吗？**
A：可以。对话模型和嵌入模型都配置为 Ollama 本地模型即可。

**Q：数据会丢失吗？**
A：数据保存在本机数据库，正常退出不丢失；建议定期备份（见「数据与隐私」）。
