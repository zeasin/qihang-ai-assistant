# 启航AI工作台（Qihang AI Desktop）

> 一款以**数据流为核心**的个人 AI 助手桌面应用——**本地优先、模型自由、数据流转起来**。你的笔记、待办、工作数据都留在本机，AI 融入数据的采集、检索、执行与复盘全流程，而不只是一个聊天窗口。

---

## ✨ 核心卖点：一条完整的自动化链路

```
采集 → 分析 → 建议 → 执行 → 推送
```

1. **采集**：Markdown 笔记随手记，JSON 数据批量导入，自动索引进本地知识库。
2. **分析**：AI 基于你的笔记和数据回答提问、查数据集、读文件，而不是凭空瞎编。
3. **建议**：AI 不只是回答问题，还给出可执行的建议——该做的事、该记的档、该跟进的事项。
4. **执行**：对话中产生的任务、记录直接落成待办和数据集，AI 还能读写笔记文件、操作本地数据、在隔离 Git worktree 中修改代码。
5. **推送**：定时提醒、每日 AI 日报自动汇总，通过飞书推送到你的群和联系人。

> 全程数据留在本机，模型可自由选择，形成"采集 → 分析 → 建议 → 执行 → 推送"的完整闭环。

## 核心功能

| 功能 | 说明 |
|------|------|
| 💬 **AI 对话** | 与 AI 对话，支持图片粘贴/上传、模型切换、流式输出和工具调用 |
| 💻 **编程** | 代码项目工作台，基于项目的 AI 编程对话，在**隔离 Git worktree** 中改代码，可审查/合并/提交/丢弃改动 |
| 📚 **知识库** | 浏览和管理本地 Markdown 笔记文件，支持关键词与语义检索 |
| 📊 **数据集** | 管理结构化数据（客户、项目、Bug 等），支持 JSON 导入导出 |
| ✅ **任务与提醒** | 待办看板、定时提醒，支持桌面通知和飞书推送 |
| 🔗 **飞书集成** | Webhook 推送消息；配置 Bot 后可在飞书里直接和 AI 对话，甚至下发编程任务 |
| 📋 **自动日报** | 每天定时汇总你的笔记、任务、对话，生成 AI 日报并推送 |
| 🧰 **工具箱** | 通用识别、识题、试卷识别、数据采集/加工等工具 |

## 快速开始

应用启动后，需要先完成以下配置才能正常使用：

### 1. 安装 pi agent（AI 对话引擎）

```bash
npm install -g @earendil-works/pi-coding-agent
```

安装后运行 `pi` 命令，按照提示完成登录和模型配置（推荐 DeepSeek 或 Ollama 模型）。

### 2. 设置笔记库目录

进入应用「设置 → 笔记库设置」，选择一个包含 Markdown 文件的本地文件夹作为笔记库。

### 3. 开始使用

完成以上配置后，即可在「对话」页开始与 AI 对话，在「知识库」浏览笔记文件，在「数据」页管理数据集。

## 开发者指南

### 环境要求

- Node.js 18+
- Git（worktree 隔离功能需要）
- 可选：Ollama（本地嵌入模型）

### 开发调试

```bash
npm install        # 安装依赖（含 Electron 原生模块编译）
npm run electron:dev   # 编译主进程 + 启动 Vite 开发服务器 + 启动 Electron
```

### 构建

```bash
npm run electron:build   # vite build + tsc 编译 + electron-builder 打包
```

### 项目结构

```
├── electron/          # Electron 主进程
│   ├── main.ts        # 入口：窗口、IPC、飞书、定时任务接线
│   ├── preload.ts     # 渲染进程桥接（contextBridge）
│   └── services/      # 核心服务
│       ├── pi-agent.ts    # pi agent SDK 集成（AI 对话引擎）
│       ├── tools.ts       # 工具定义（笔记/数据集/编码/日报/搜索）
│       ├── worktree.ts    # Git worktree 隔离执行服务
│       ├── coding-task.ts # 飞书编程任务引擎（隔离执行 + 变更审查）
│       ├── feishu.ts      # 飞书 WebSocket 长连接 / Webhook
│       ├── database.ts    # SQLite 本地数据库
│       ├── rag.ts         # 知识库索引与语义检索
│       └── ...
└── src/               # 渲染进程（Vue 3）
    ├── views/         # 页面（对话/编程/知识库/数据/任务/设置...）
    └── components/    # 组件
```

## 飞书使用指南

### 1. Webhook 推送

粘贴飞书群机器人 Webhook 地址，AI 日报、提醒即可推送到群。

### 2. Bot 对话

在飞书开放平台创建应用，填 `App ID` / `App Secret`，启动后可在飞书私聊/群聊中直接使用 AI。

### 3. 飞书编程指令

| 指令 | 说明 |
|------|------|
| `列出项目` | 列出所有已配置的代码项目（类型为「代码库」） |
| `切换到 <项目名或序号>` | 绑定当前要操作的代码项目，后续消息默认在该项目执行 |
| `/code：<项目名或序号> <任务>` | 明确指定项目并下发编程任务（也支持 `code：` 前缀） |
| `查代码：<问题>` | 在已绑定/识别到的代码项目中排查问题 |
| 消息里直接带项目名 | 自动识别消息中包含的项目名并路由到编程任务 |

**示例**：

```
列出项目
切换到 启航工作台
/code：启航工作台 修复登录接口的超时问题
```

> AI 编程任务在 **Git worktree 隔离目录**中执行，**绝不改动你的原项目目录**；改动的代码可在「编程」页审查、合并、提交或丢弃。

## 配置指南

### 1. LLM 对话模型（必配）

通过终端运行 `pi` 命令配置模型，支持：
- **DeepSeek**：填 API Key 选择模型
- **OpenAI 兼容接口**：任何 OpenAI 兼容的服务商
- **Ollama（本地/离线）**：填服务地址和模型名

配置后应用自动识别，对话页也可临时切换模型。

### 2. 定时任务与日报

「设置 → 定时任务」中可配置：

- **自动日报**：每天定时汇总笔记、任务、对话生成日报（可自定义提示词模板，推送到飞书）
- 支持定时索引等任务

## 数据与隐私

- 所有数据保存在本机数据库（`~/.qihang-ai-desktop/qihang-ai-desktop.db`）与你的笔记文件夹中。
- 对话内容默认会发送给你配置的模型服务商（DeepSeek 等）用于生成回复。
- 如需**完全离线**：使用 Ollama 作为对话模型与嵌入模型即可（除软件自动更新外无任何网络请求）。
- 飞书凭据等敏感配置保存在本机 `config.json`（已加入 `.gitignore`，不会进入仓库）。

## 常见问题（FAQ）

**Q：提示"模型连接失败"？**
A：运行 `pi` 检查模型配置，Ollama 需先 `ollama pull <模型名>` 并确保服务已启动。

**Q：可以完全离线使用吗？**
A：可以。对话模型配置为 Ollama 本地模型即可。

**Q：数据会丢失吗？**
A：数据保存在本机数据库，正常退出不丢失。可在「设置 → 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份），或从备份文件一键恢复（恢复后重启应用生效）。

**Q：编程任务会改坏我的代码吗？**
A：不会。编程任务默认在隔离的 Git worktree 中执行，你的原项目目录保持不动；改动的代码需要你在「编程」页审查后才合并。
