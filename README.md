# 启航AI工作台（Qihang AI Desktop）

> 一款以**数据流为核心**的个人 AI 助手桌面应用——**本地优先、模型自由、数据流转起来**。你的笔记、待办、工作数据都留在本机，AI 融入数据的采集、检索、执行与复盘全流程，而不只是一个聊天窗口。

## ✨ 核心卖点：一条完整的自动化链路

```
采集 → 分析 → 建议 → 执行 → 推送
```

1. **采集**：Markdown 笔记随手记，JSON 数据批量导入，自动归档进本地笔记库。
2. **分析**：AI 基于你的笔记、数据和项目管理回答提问、查数据集、读文件，而不是凭空瞎编。
3. **建议**：AI 不只是回答问题，还给出可执行的建议——该做的事、该记的档、该跟进的事项。
4. **执行**：对话落成定时/循环任务和数据集记录，AI 还能读写笔记文件、操作本地数据、在隔离 Git worktree 中修改代码。
5. **推送**：定时提醒、每日 AI 日报自动汇总，通过飞书推送到你的群和联系人。

> 全程数据留在本机，模型可自由选择，形成"采集 → 分析 → 建议 → 执行 → 推送"的完整闭环。

## 核心功能

| 功能 | 说明 |
|------|------|
| 💬 **AI 对话** | 多轮对话、图片粘贴/上传与识别、模型切换、流式输出；内部含「对话 / 知识库 / 概览」三个 Tab |
| 📚 **知识库** | 「AI」页内 Tab：浏览预览笔记库 Markdown 文件、文件名搜索、让 AI 基于笔记回答问题 |
| 📊 **概览** | 「AI」页内 Tab：统计卡片、综合日报、待办、提醒、待处理记录看板 |
| 🔔 **任务中心** | 笔记任务 / 代码任务 / 代码库三个 Tab，支持立即、指定时间、定时循环（每天/每周/每月/Cron）触发，结果自动保存到笔记库并可选推送飞书 |
| 💻 **AI 编程** | 「任务」页代码库 Tab：基于项目的 AI 编程对话，在**隔离 Git worktree** 中改代码，可审查/合并/提交/丢弃改动 |
| 🗃️ **数据集** | 多数据集管理、自定义 Schema（文本/数字/金额/日期/下拉等）、内置模板一键安装、AI 业务分析、JSON 粘贴/URL 导入 |
| 📅 **提醒** | 每日/每周/每月/每年/一次性提醒，系统通知 + 飞书推送 |
| 🔧 **工具箱（beta）** | 演示大纲（PPTX/HTML）、周报日报、思维导图（.mm）、文案、网站抓取、图片生成 |
| 🔗 **飞书集成** | Webhook 推送消息；配置 Bot 后可在飞书里直接和 AI 对话，甚至下发编程任务 |
| 📋 **自动日报** | 每天定时汇总你的笔记、任务、对话，生成 AI 日报并推送（支持自定义提示词） |

## 快速开始

应用启动后，需要先完成以下配置才能正常使用：

### 1. 配置 AI 对话大模型

进入应用「设置 → 💬 对话模型配置」，填写接入点信息：接入名称、服务地址（API Base URL）、API Key、模型名称。支持 OpenAI 兼容接口（如 DeepSeek、Ollama、LM Studio 等），可配置多个接入，每个接入可包含多个模型。保存后立即生效，点「测试」可验证连接。无需安装任何终端工具。

### 2. 设置笔记库目录

进入应用「设置 → 📚 笔记库设置」，选择一个包含 Markdown 文件的本地文件夹作为笔记库。

### 3. 开始使用

完成以上配置后，即可在「AI」页开始与 AI 对话（顶部可切换知识库/概览），在「任务」页创建定时任务，在「数据」页管理数据集。

## 开发者指南

### 环境要求

- Node.js 18+
- Git（worktree 隔离功能需要）
- 可选：Ollama（本地对话模型）

### 开发调试

```bash
npm install        # 安装依赖（含 Electron 原生模块编译）
npm run electron:dev   # 编译主进程 + 启动 Vite 开发服务器 + 启动 Electron
```

### 构建

```bash
npm run electron:build   # vite build + tsc 编译 + electron-builder 打包
```

### 项目结构

```
├── electron/          # Electron 主进程
│   ├── main.ts        # 入口：窗口、IPC、飞书、定时任务接线

│   ├── worker/        # 数据库 Worker
```

## 飞书使用指南

### 1. Webhook 推送

粘贴飞书群机器人 Webhook 地址，AI 日报、提醒即可推送到群。

### 2. Bot 对话

在飞书开放平台创建应用，填 `App ID` / `App Secret`，启动后可在飞书私聊/群聊中直接使用 AI。

### 3. 飞书编程指令

| 指令 | 说明 |
|------|------|
| `列出项目` | 列出所有已配置的代码项目（类型为「代码库」） |
| `切换到 <项目名或序号>` | 绑定当前要操作的代码项目，后续消息默认在该项目执行 |
| `/code：<项目名或序号> <任务>` | 明确指定项目并下发编程任务（也支持 `code：` 前缀） |
| `查代码：<问题>` | 在已绑定/识别到的代码项目中排查问题 |
| 消息里直接带项目名 | 自动识别消息中包含的项目名并路由到编程任务 |

**示例**：

```
列出项目
切换到 启航工作台
/code：启航工作台 修复登录接口的超时问题
```

> AI 编程任务在 **Git worktree 隔离目录**中执行，**绝不改动你的原项目目录**；改动的代码可在「任务 → 代码库」的「审查变更」中审查、合并、提交或丢弃。

## 配置指南

### 1. 对话模型（必配）

「设置 → 💬 对话模型配置」，支持：
- **DeepSeek**：内置快捷配置模板，填 API Key 选择模型
- **OpenAI 兼容接口**：任何 OpenAI 兼容的服务商（硅基流动、云端等有快捷模板）
- **Ollama（本地/离线）**：填服务地址和模型名

可配置多个接入、每个接入多个模型，保存后立即生效；对话页输入框上方可随时切换模型。

### 2. 任务与日报

- 「任务」页可创建笔记/代码任务，设置立即执行、指定时间或定时循环触发，结果保存到笔记库，可选推送飞书
- 「设置 → 综合日报设置 / 日报 AI 提示词」管理每日 AI 日报的保留天数与生成提示词

## 数据与隐私

- 所有数据保存在本机数据库（`~/.qihang-ai-desktop/qihang-ai-desktop.db`）与你的笔记文件夹中，不上传任何云端（除非你手动启用云端数据库）。
- 对话内容默认会发送给你配置的模型服务商（DeepSeek 等）用于生成回复。
- 如需**完全离线**：使用 Ollama 作为对话模型即可（除软件自动更新外无任何网络请求）。
- 飞书凭据等敏感配置保存在本机 `config.json`（已加入 `.gitignore`，不会进入仓库）。

## 常见问题（FAQ）

**Q：对话为空或超时？**
A：对话模型未配置或配置有误。在「设置 → 💬 对话模型配置」填写服务地址、API Key 和模型名称，并点「测试」验证。

**Q：AI 答非所问，没有用到笔记？**
A：笔记库未设置。在「设置 → 📚 笔记库设置」选择包含 Markdown 文件的文件夹，重新提问。

**Q：提示"模型连接失败"？**
A：在「设置 → 💬 对话模型配置」检查服务地址/API Key/模型名称并点「测试」验证，Ollama 需先 `ollama pull <模型名>` 并确保服务已启动。

**Q：可以完全离线使用吗？**
A：可以。对话模型配置为 Ollama 本地模型即可。

**Q：编程任务会改坏我的代码吗？**
A：不会。编程任务默认在隔离的 Git worktree 中执行，你的原项目目录保持不动；改动的代码需要你在「任务 → 代码库」的「审查变更」中人工合并、提交后才生效。

**Q：数据会丢失吗？**
A：数据保存在本机数据库，正常退出不丢失。可在「设置 → 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份），或从备份文件一键恢复（恢复后重启应用生效）。
